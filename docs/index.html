OUR PHILOSOPHY

我們只挑選,
經得起精準對待的豆子。

市面上多數「高階咖啡豆」賣的是故事,我們賣的是可以被重複驗證的風味。每一批豆子進到店裡前,都先通過杯測與烘焙曲線的雙重審核 ── 只有經得起數據檢驗的豆子,才配得上一張手沖藍圖。

我們與中南美洲、東非的小農莊直接合作,採單一莊園、小批量進口,並在每包豆子上標註完整的產地履歷,讓每一次沖煮,都有跡可循。

THE BLUEPRINT

五個步驟,決定一杯咖啡的誠實度。

01 / WEIGH

秤重

以電子秤量測咖啡粉與水,誤差控制在 0.1 克內。

粉量 15g

02 / GRIND

研磨

中細研磨,確保顆粒均勻,避免過度萃取的雜味。

中細 / 白糖顆粒感

03 / BLOOM

悶蒸

小水量喚醒咖啡粉,讓封存的二氧化碳釋放出來。

30 秒

04 / POUR

注水

分三段緩慢注水,水流維持穩定,不沖刷濾紙邊緣。

3 段式 / 細口壺

05 / EXTRACT

萃取

控制總時間與萃取率,萃出乾淨而有層次的風味。

2:45 / 萃取率 20%
